# 画像の入れ方

このフォルダに**下の名前で画像を置くだけ**で、サイトに自動で反映されます。
HTMLを触る必要はありません。ファイルが無い場合は「撮影予定」のカードが表示されるので、
1枚ずつ差し替えていっても崩れません。

## ファイル名と用途

| ファイル名 | 使われる場所 | 推奨サイズ | 内容の目安 |
| --- | --- | --- | --- |
| `hero-1.jpg` | トップ最上部・スライド1枚目 | 1600×1200 以上 | ご相談の様子（テーブル越しの対話・手元と書類） |
| `hero-2.jpg` | トップ最上部・スライド2枚目 | 1600×1200 以上 | セミナー会場（後方からの引き） |
| `hero-3.jpg` | トップ最上部・スライド3枚目 | 1600×1200 以上 | スタッフ集合／オフィス全景 |
| `seminar.jpg` | トップ「セミナー」枠 | 1200×1000 以上 | セミナー風景 |
| `daihyo.jpg` | トップ・会社情報の代表挨拶 | 900×1100 以上（縦長） | 代表ポートレート |
| `activity-1.jpg` | トップ「活動の様子」1枚目 | 1200×900 以上 | セミナー風景 |
| `activity-2.jpg` | トップ「活動の様子」2枚目 | 1200×900 以上 | 個別相談 |
| `activity-3.jpg` | トップ「活動の様子」3枚目 | 1200×900 以上 | オフィス |
| `staff-1.jpg` 〜 `staff-3.jpg` | 会社情報・スタッフ紹介 | 800×800（正方形） | 顔写真 |

- 形式は `.jpg` 推奨（`.png` を使う場合は HTML 側の拡張子も変更が必要です）
- 表示は自動でトリミングされます（`object-fit: cover`）。**被写体は中央寄り**だと安全です
- 1枚 **300KB 以下**が目安。大きすぎるとページが重くなります

## 撮影・素材のメモ

- 実写が最優先です。AI生成画像は、金融・不動産の信頼性の観点から本番では使わない想定です
- ストック素材を使う場合は、商用利用可のライセンスであることをご確認ください
- 顔がはっきり写る素材は、掲載許可の有無にご注意ください
