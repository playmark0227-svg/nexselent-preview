# 画像管理メモ

現在のプレビューでは、内容に合う構図を確認するためAI生成のイメージ写真を使用しています。HTMLはWebPを優先し、同名のJPEGをフォールバックとして読み込みます。

## 現在使用中の画像

| ファイル名 | 使われる場所 | 内容 |
| --- | --- | --- |
| `consultation-hero-v2.*` | トップのメイン画像 | FPと夫婦による家計・住まいの相談 |
| `seminar-session-v2.*` | トップ／セミナーページ | 札幌の少人数マネーセミナー |
| `house-planning-v2.*` | 不動産・建築 | 間取りと資金計画を同時に確認する相談 |
| `lifeplan-consultation-v1.*` | ライフプラン | 家族の予定を時間軸で整理する相談 |
| `lifeline-review-v1.*` | ライフライン | 電気・通信など固定費の比較 |
| `branding-session-v1.*` | ブランディング | 地域事業者とのWeb・発信企画 |
| `recruit-team-v1.*` | 採用情報 | チーム内の提案検討・育成風景 |

`*` は `.webp` と `.jpg` の2形式です。画像は中央寄りに構成し、ページ側の `object-fit: cover` で画面幅に応じてトリミングします。1ファイル300KB以下を目安にします。

## 本番公開前の方針

- 写真は相談内容を伝えるイメージ素材です。画面上の生成方法の注記は省き、制作記録はこの管理メモに残しています
- 金融・不動産の信頼性を高めるため、本番では掲載許可を得た実写への差し替えを推奨します
- 代表・スタッフなど実在人物を示す欄には生成人物を使用しません。本人写真のない人物紹介枠は設けていません
- 実セミナーや相談風景を使う場合は、写っている方全員の掲載許可をご確認ください
- ストック素材を使う場合は、商用利用条件とクレジット要否をご確認ください
